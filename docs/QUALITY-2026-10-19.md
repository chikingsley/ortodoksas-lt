# Toolchain and editor maintenance

Current dependency versions and fresh source verification are recorded in [the October 20 dependency review](DEPENDENCIES-2026-10-20.md). The October 20 review found the Vite wildcard waiver still present in this repository and removed it with strict peer validation. That live configuration corrects the earlier waiver-removal statement below.

Reviewed on 2026-10-19. Both publications use the same editorial architecture with independent content, accounts, databases, media buckets and Worker deployments.

## Enforced checks

The normal pnpm check command requires zero lint findings and runs formatting, strict TypeScript, content and editor contracts, real Cloudflare Worker tests, builds, bundle budgets and deployment dry runs. The historical lint baseline has been removed. Copied Tiptap components receive the same checks as application code.

Ultracite 8 uses its OXC core, React, TanStack, shadcn, test and anti-slop presets. Additional limits are cyclomatic complexity 15, nesting depth 4 and five parameters. Oxfmt uses the upstream 80-column layout target; long URLs and indivisible strings retain their literal contents. TypeScript enables strict mode, unchecked-index checks, implicit-return checks and switch-fallthrough checks in application and tooling projects.

## Dependencies and concrete compatibility decisions

- Tiptap packages are 3.32.0. The copied UI was refreshed from the official registry, including the current find-and-replace extension. The adjacent TIPTAP-SOURCE.json records upstream paths and content hashes. Local adapters preserve canonical publication JSON, R2 uploads, React 19 refs, subscription cleanup, keyboard navigation, mobile layout and site design tokens. Unused barrels, the unused textarea primitive and the unused unmount hook have been removed.
- Vite 8.3.4 and Cloudflare's Vite plugin 1.64.0 run together with strict peer resolution. The old Vite peer waivers and broad minimum-release-age exclusions have been removed. Cloudflare's resolve.external restriction applies to application dependencies; Node built-ins are supported by the current plugin. Both builds bundle the Worker dependencies.
- The exact Wrangler 4.151.2, Miniflare and workerd platform versions released on 2026-10-19 have explicit age-gate entries because this requested latest-release upgrade falls inside pnpm 12’s default 24-hour window. A frozen installation without those entries was tested and rejected these eight exact packages. The ordinary age gate remains active for future versions; these entries become redundant after the release window.
- Vite 8.3.4 has a one-line CSS source-map patch: the CSS renderChunk hook now reads the current environment’s build.sourcemap setting. Cloudflare enables server maps independently of the root client settings; using the root flag discarded the generated map. The initially proposed upstream server-transform change did not repair this build path, so the patch targets the reproduced cause. Source maps and their diagnostics remain enabled.
- Wrangler 4.151.2 includes the current workerd and binding declarations. Bindings were regenerated and tested in the actual Worker runtime.
- Studio and shared packages use TypeScript 7.0.2. The Astro application uses 6.0.3 because @astrojs/check 0.9.10 declares support for TypeScript 5 and 6. Each application runs its own compiler. Strict peer checking enforces that boundary.
- skipLibCheck covers vendor declaration files. A verification run with it disabled reproduced duplicate browser and Worker globals plus Drizzle's own SQLite and optional-driver declaration errors. Application source remains strictly checked, and Worker APIs run in workerd tests. Future dependency upgrades should repeat this probe before removing the setting.
- TanStack React Router 1.170.45 retains its resolved lazy import and calls React use consistently on subsequent renders, matching the fix discussed in [upstream issue 8487](https://github.com/TanStack/router/issues/8487) and [PR 8549](https://github.com/TanStack/router/pull/8549). The patch covers its ESM, CommonJS and source modules. The full Studio browser flow reproduced the warning before this fix.
- TanStack's current route CLI ships a CommonJS launcher that reads replaceRouteChunk during a circular import. The generate-routes command loads the same published CLI through its ESM export, with the same generate arguments. This removes the CommonJS initialization warning while retaining the vendor's generator.
- pnpm 12.14.0 enforces strict peer dependencies and lockfile supply-chain checks. The esbuild override upgrades vulnerable transitive versions through 0.24.2 to the current 0.28 line. The braces 3.0.3 patch bounds parser and recursive-walker depth; its advisory exception is tied to that patch and executable regression tests. The upstream maintainer still disputes the advisory, so the local protection remains necessary until a verified upstream replacement lands.

## Narrow lint decisions

- TypeScript noImplicitReturns replaces the redundant OXC consistent-return check, following OXC's recommendation.
- OXC react/todo is a compiler optimization hint for features under development. React correctness and Hooks rules remain active.
- Exact boolean test assertions remain exact. Unit tests retain the preset limit of five assertions; Worker state-transition scenarios allow twenty, and the complete translation-review sequence allows thirty-two.
- TanStack's published Response and Redirect control-flow types are allowed throw values. Unknown and any thrown values remain rejected.
- Astro component filenames follow PascalCase, and the historical apie_egzarchata route retains its existing URL.
- The shadcn allowlist contains exact Tiptap SCSS selectors. The client-bundle test verifies every allowed selector against the CSS actually shipped by the build.
- Inline exceptions name the specific contract: synchronous Zod fallbacks, synchronous Standard Schema form validation, XMLHttpRequest upload progress, React's updater-function unions, Base UI's typed value unions, ProseMirror's non-array map method, Cloudflare's generated byte-stream type, catch-boundary narrowing, and ARIA grouping semantics. Bounded live crawls intentionally await each request within a small worker pool.
- Generated bindings, generated routes, vendored assets and downloaded source snapshots are excluded from formatting and linting. Authored source and maintained migration and deployment tools remain checked.

## Repository files and publishing

Files ending in .spec.ts are automated regression tests. public-editorial-output.spec.ts checks real generated pages for source fidelity and public presentation; it is test code. Maintained import tools live in migration/src, deployment configuration in deployment, and checks in tests or each application's test directories. Temporary investigation fixtures and screenshots remain in the originating task workspace.

Both Studios manage articles, translations, revisions, media, people and communities. Sign-in targets the article inventory and refreshes the document for an already authenticated session, ensuring server route guards read the current cookie. Imported revision metadata accepts an optional title, matching legacy source-only snapshots. OBL additionally carries its seven-language institutional content and service schedules. Editorial saves write canonical Tiptap JSON and increment the publication revision, which invalidates public caches. Content publishing uses that workflow; software releases deploy Workers.

OBL's cream and green palette follows its supplied brief. Ortodoksas uses its white and burgundy publication design. Public pages omit unavailable publication dates and preserve source ordering. Editorial provenance stays in the private workflow. Mobile editor controls use 44px targets, labeled actions and a link field that stays within the toolbar at 320px.

## Verification

The full repository checks passed with zero lint findings and type errors. Browser checks covered sign-in, imported article loading, saves with independent local database readback, translation switching, formatting, search and replacement, and 320px editor controls. The deployed publications passed 3,448 article-page checks and 136 responsive-layout cases across 320px to 1440px. Database integrity and foreign-key checks passed. Publication revision reads cost one row and recent-article selectors read twenty rows.

A final invalid-URL check reproduced a D1 offset error for non-finite search page numbers. The page parser now accepts positive safe integers and bounds offsets; content tests and Worker response-body tests cover the regression.
